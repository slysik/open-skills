## (b) Gap list, prioritized for a Cloud Solution Architect interview (highest first)

1. **Fabric IQ: ontology updates + Planning + IQ MCP/Copilot Chat (items 7, 8, 15).** Fabric IQ is the headline AI-readiness story; the skills cover only the basic ontology definition and the Power BI MCP path. Planning has no coverage at all, and its GA claim needs reconciling with Learn.
2. **Mirroring build path (item 13).** Mirroring is a core data-estate topic (Cosmos DB, SQL, BigQuery, Snowflake). Skills explain it but cannot create or monitor a mirrored database; Learn documents a full REST surface.
3. **Fabric policies / OneLake catalog guardrails (item 9).** Governance and "who can create what" is a standard CISO/CDO conversation; this is the missing control next to the governance audit skill.
4. **Deployment plans (item 1).** ALM is a recurring design-session topic; skills explain deployment pipelines but not the new orchestration canvas.
5. **Monitoring hub + operations agent (item 2).** Operations and resiliency story; the skills only reference the old portal location and an instruction-generation path.
6. **Database hub + database agents (items 3, 4).** Relevant when the customer runs SQL, PostgreSQL and Cosmos fleets (Cosmos DB in Fabric and mirrored databases are *not* supported by the hub).
7. **Eventhouse and business events (item 12).** Real-time and IoT scenarios; update policies are covered, business events and acceleration are not.
8. **Fabric Apps (item 5).** Novel and developer-facing; useful for "AI-ready app back end" discussions but preview and CLI-only.
9. **Copilot in Fabric unified experience (item 16).** Needs Learn to publish docs before a skill can be accurate.
10. **GPU-accelerated warehouse (item 11).** Limited preview, five regions, portal toggle; low interview relevance but a good "preview vs GA" example.
11. **IQ sharing (item 10).** No Learn page; do not build anything until documented.
